# OpenAI Game

공모전 제출용 Unity 프로젝트와 팀원별 프로토타입을 분리해 관리하는 저장소입니다.

## 프로젝트 구조

- `RPG DEMO/`: 공모전 제출용 메인 Unity 프로젝트 (`dev/yunchae`의 RPG 프로토타입 기반)
- `Prototypes/DohyunPrototype/`: 도현 프로토타입 보관본
- `Test project/`: 초기 Unity 테스트 프로젝트

Unity Hub에서는 저장소 루트가 아니라 작업할 프로젝트 폴더를 직접 선택해야 합니다.
메인 프로젝트 개발 시 `RPG DEMO/`를 열어 주세요.

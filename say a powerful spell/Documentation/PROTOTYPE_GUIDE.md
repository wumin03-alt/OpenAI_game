# Say a Powerful Spell — 프로토타입 가이드

## 바로 실행하기

1. Unity가 스크립트 임포트와 컴파일을 끝낼 때까지 기다립니다.
2. `Assets/Scenes/SampleScene`을 연 상태에서 Play를 누릅니다.
3. **스테이지 모드 입장 → STAGE 01 → 도전하기**를 누릅니다.
4. 아래 주문 카드에서 스킬을 고른 뒤 `주문 말하기` 또는 Space 키를 사용합니다.

씬에 프리팹을 배치할 필요가 없습니다. 런타임 부트스트랩이 게임을 자동 생성합니다.

## 음성 인식 — 오프라인 Whisper 전용

- API 키와 계정이 필요하지 않습니다. 모델을 설치한 뒤 플레이할 때는 인터넷 연결도 필요하지 않습니다.
- GitHub에는 대용량 모델을 올리지 않습니다. 프로젝트를 처음 받은 팀원은 Unity 상단의 **Powerful Spell → Whisper 모델 설치 및 확인**을 한 번 실행합니다.
- 설치 창이 공식 `whisper.cpp` 다국어 `small` 모델(약 466MiB)을 내려받고 SHA-1을 검증합니다.
- 모델 파일은 `.gitignore` 처리되어 각 개발 PC에만 존재하며 commit/push에 포함되지 않습니다.
- 음성은 외부 서버로 전송되지 않고 플레이어 PC에서만 처리됩니다.
- Space를 한 번 누르고 주문을 말하면, 주문 길이에 따라 약 0.55~0.9초간 조용해진 뒤 자동 분석합니다.
- 기본 `small` 모델 크기는 약 466MiB이며 첫 판정과 저사양 PC에서는 잠깐 지연될 수 있습니다.
- Play 시작 시 로컬 인식 서버가 모델을 한 번만 메모리에 올립니다. 이후 주문마다 모델을 다시 읽지 않아 연속 판정이 빨라집니다.
- 분석 오디오 범위를 약 20초로 제한해 현재 최장 주문까지 처리하면서 CPU 판정 시간을 줄였습니다.
- 정답 문장 전체와 문장 순서는 Whisper 프롬프트로 전달하지 않습니다. 대신 `찹쌀`, `법학박사`, `철창살`처럼 받아쓰기가 자주 무너지는 고유 어휘 목록만 제공해 혀 꼬임 발음을 일반 단어로 바꾸는 현상을 줄입니다.
- 반복 자모(`ㄱㄱㄱ…`), 반복 영문(`xxxx…`), 영어 위주의 비정상 결과는 주문 실패로 비교하지 않고 잘못된 인식으로 폐기해 재시도를 안내합니다.
- `whisper.cpp` 코드는 MIT 라이선스이며 배포 폴더에 라이선스 고지 파일을 포함했습니다.
- 녹음과 분석 중에는 몬스터 공격 타이머가 정지하며 판정 후에도 1.1초의 행동 여유가 생깁니다.

## 마이크가 작동하지 않을 때

- Windows **설정 → 개인정보 및 보안 → 마이크**에서 마이크 접근과 데스크톱 앱 접근을 켭니다.
- Unity Play 화면의 **음성 설정**에서 `마이크 상태`가 `권한 거부됨` 또는 `입력 장치 없음`인지 확인합니다.
- 설정 화면의 좌우 화살표로 Whisper가 사용할 마이크를 선택할 수 있습니다. 선택은 다음 실행에도 저장됩니다.
- `2초 녹음 후 재생` 중에는 실제 마이크 음량 게이지가 움직입니다. 녹음 결과는 실제 구간만 잘라 자동 증폭한 뒤 재생합니다.
- 게이지가 전혀 움직이지 않으면 장치 또는 마이크 권한 문제입니다.
- 마이크 테스트는 정상인데 전투에서 시작되지 않으면 설정 화면의 Whisper 상태를 확인합니다. `모델이 설치되지 않았습니다`가 보이면 Unity 상단의 **Powerful Spell → Whisper 모델 설치 및 확인**을 실행합니다.
- 모델 다운로드가 중단되거나 파일이 손상되면 같은 설치 창의 **모델 다시 설치**를 사용합니다.

## 팀원 최초 설정

1. GitHub에서 프로젝트를 clone 또는 pull합니다.
2. Unity에서 프로젝트를 열고 스크립트 컴파일을 기다립니다.
3. 상단 메뉴 **Powerful Spell → Whisper 모델 설치 및 확인**을 엽니다.
4. **공식 모델 다운로드 및 설치**를 누릅니다.
5. `설치 완료 · SHA-1 검증 정상`이 표시되면 Play를 완전히 종료했다가 다시 시작합니다.

모델은 GitHub나 Git LFS를 사용하지 않고 팀원마다 한 번만 내려받습니다. 완성된 게임을 배포할 때는 빌드한 개발 PC에 모델이 설치되어 있어야 하며, Unity가 `StreamingAssets`의 모델을 Windows 빌드에 포함합니다.

## 전투 중 음성 표시

- 조작은 **Space 한 번 누르기 → 키에서 손 떼기 → 주문 말하기**입니다. 누르고 있을 필요가 없고 두 번 누르지 않습니다.
- 대기 상태: `SPACE를 한 번 누른 뒤 주문을 외우세요!`
- 녹음 상태: `지금 주문을 외우세요! 말을 마치면 자동으로 판정됩니다`
- Whisper: 실제 마이크 음량을 표시하며, 발화가 끝나면 자동으로 녹음을 끝내고 로컬 분석
- 최종 판정: 인식된 문장과 유사도 점수 표시

## 프로토타입 사운드

별도 음원 라이선스 없이 바로 테스트할 수 있도록 코드에서 다음 소리를 실시간 합성합니다.

- 저음 마법 배경 분위기음
- 버튼/주문 선택음
- 마이크 듣기 시작음
- 주문 성공과 실패음
- 몬스터 공격음
- 스테이지 승리와 패배음

추후 실제 캐릭터와 아트 방향이 결정되면 이 합성음을 정식 BGM, 효과음, 성우 음성으로 교체하면 됩니다.

합성 배경음에서 노이즈 파형을 제거하고 전체 효과음 음량을 절반 이하로 낮췄습니다.

## 주문 성공 판정

완전 일치만 요구하지 않지만 한 지표만 높다고 성공시키지 않습니다. 다음 점수를 합산하고 각 항목의 최소 기준도 검사합니다.

- 글자 편집 유사도: 24%
- 한글 초성·중성·종성 발음 유사도: 30%
- 글자 순서 일치: 16%
- 연속 2글자 음절 일치: 18%
- 핵심 단어 포함률: 12%

현재 판정 기준:

- 일반 주문: 종합 유사도 68%
- 65자보다 긴 주문: 종합 유사도 66%
- 필살기: 종합 유사도 64%

물음표, 쉼표, 마침표를 포함한 특수문자와 띄어쓰기는 판정 전에 제거합니다. 발화 길이와 자모 순서를 유지한 문장은 `찹쌀→첩살`, `법학→팝팝`, `드르륵→뚜루룩`처럼 Whisper 표기가 무너져도 발음 중심 복구 판정으로 성공할 수 있습니다. 짧은 부분 발화와 길이가 비슷한 다른 문장은 계속 실패합니다.

전체 유사도와 별개로 마지막 30~40%의 자모 진행, 마지막 종결 음절, 최종 단어를 필수 검사합니다. 마지막 한두 단어를 생략하면 전체 점수가 높아도 실패합니다. `열었는가`처럼 문장 안에서 종결어가 반복되는 주문은 필요한 반복 횟수도 모두 충족해야 합니다.

찹쌀 탄환은 짧은 주문이므로 전체 발화 길이 92% 이상을 요구해 중간의 두 번째 `찹쌀`까지 모두 말해야 합니다. 구름 그림 폭풍은 Whisper가 반복되는 `그린 구름`을 합쳐 받아쓰는 특성이 확인되어 78%까지 허용하지만, 마지막 `깃털구름 … 구름 그림이다` 종결 검사는 그대로 유지합니다.

발화 종료 침묵 시간은 일반 주문 0.55초, 65자 이상 주문 0.7초, 필살기 0.9초입니다. 예상 주문 길이보다 지나치게 이른 시점의 짧은 호흡은 문장 종료로 취급하지 않으며, 이때는 1.15초 침묵해야 종료됩니다. 최대 녹음 시간은 35초입니다.

성공하면 전투 중앙에 초록색 `주문 성공!` 배너와 정확도·피해량·콤보를 표시합니다. 실패하면 빨간색 `주문 실패...` 배너와 유사도를 2.1초 동안 표시합니다.

## 주문 난이도와 피해량

일반 주문은 스테이지 진행에 따라 해금되며 발음 난이도가 높을수록 피해량이 증가합니다.

1. 찹쌀 탄환 — 22 피해
2. 도토리 개문 — 36 피해
3. 법학박사의 판결 — 54 피해
4. 솥장수의 불꽃 — 78 피해
5. 구름 그림 폭풍 — 108 피해

## 콤보와 필살기

- 일반 주문을 연속 성공할 때마다 콤보가 1 증가합니다.
- 콤보 피해 배율은 1콤보 1배에서 시작해 성공할 때마다 0.12배 증가하며 최대 2배입니다.
- 주문 실패 시 콤보가 0으로 초기화됩니다.
- 5콤보 달성 시 여섯 번째 카드 `철창살 대심판`이 활성화됩니다.
- 필살기의 기본 피해는 240이며 현재 5콤보 배율까지 적용됩니다.
- 필살기 성공 시 콤보를 소비하여 0으로 초기화합니다.
- 필살기 실패 시에도 연속 성공이 끊겨 콤보가 초기화됩니다.

## 현재 구현 범위

- 시작 화면과 5단계 스테이지 선택
- 정면 대치형 2D 전투 화면
- 스테이지별 몬스터 체력/공격력/공격 주기
- 몬스터는 음성 없이 주기적으로 즉시 스킬 사용
- 5개 주문, 단계별 해금, 피해량과 쿨다운
- 연속 성공 콤보와 최대 2배 피해 보너스
- 고등급 주문의 텍스트 깜빡임/단어 가림 방해
- 번들형 오프라인 Whisper 한국어 음성 인식
- API 없이 전투를 검증하는 문장 테스트 입력
- PlayerPrefs 기반 진행도 저장

## 개발용 메뉴

Unity 상단 메뉴의 **Powerful Spell**에서 진행도를 초기화하거나 전부 해금할 수 있습니다. 메뉴 실행 후 Play를 다시 시작하면 반영됩니다.

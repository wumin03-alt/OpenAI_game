# Boss Stage — DEEP//SICK Adaptive Core

## 한 문장 목표

플레이어가 자신의 습관을 읽는 AI 보스에게 일부러 가짜 전투 데이터를 먹이고, 패링으로 학습 모델을 망가뜨리며 역으로 공략하는 횡스크롤 보스전이다.

## 전투 흐름

1. **Observe / Phase 1**: 보스가 근접·원거리 공격 비중, 공중 체류, 좌우 회피 성향, 대시와 패링을 기록한다.
2. **Analysis**: HP 50%에서 시간을 멈추고 관찰 결과, 데이터 무결성, 보스가 장착할 카운터를 공개한다.
3. **Adapt / Phase 2**: 학습 결과에 맞춰 근접 밀어내기, 원거리 추격, 대공 탄막, 지상 예측 강하의 사용 비율을 높인다.
4. **Disrupt**: 성공 패링은 보스를 경직시키고 적응 강도를 낮춘다. Phase 1에서 충분히 성공하면 데이터가 오염되어 보스가 공격 성향을 반대로 학습한다.
5. **Resolve**: 보스 또는 플레이어 사망 시 결과와 재시작 입력을 제공한다.

## UI 구성

- 기존 상단 보스/플레이어 HP UI는 유지한다.
- 우측 상단 `Adaptive Core HUD`에서 현재 관찰 중인 공격·이동·회피 성향을 표시한다.
- Phase 1에는 `DATA INTEGRITY`, Phase 2에는 `ADAPTATION STRENGTH` 게이지를 표시한다.
- Phase 2에는 보스가 장착한 카운터 프로토콜을 직접 공개한다.
- 화면 중앙 분석 패널에서 전환 시 전체 학습 결과를 순서대로 보여준다.
- 승리/패배 오버레이에서 Enter로 즉시 재도전할 수 있다.

## 보스 형태

- 기존 거대 호버형 보스 실루엣을 유지해 현재 애니메이션/히트박스와 호환한다.
- 중앙 학습 코어와 회전하는 6개 데이터 노드를 런타임에 추가한다.
- Phase 1은 청록색 관찰 상태, Phase 2는 적색/자홍색 적응 상태, 패링 교란은 흰색 글리치로 표현한다.
- 새 외부 아트 에셋 없이 동작하므로 WebGL 빌드와 팀 브랜치 병합 부담을 줄인다.

## 학습 입력과 카운터

| 관찰 데이터 | 판정 | 보스 대응 |
|---|---|---|
| 근접 공격 우세 | Close Range | Tail Sweep, Ascend, 원거리 견제 증가 |
| 원거리 공격 우세 | Long Range | Descend, Sky Dive 추격 증가 |
| 공중 체류 우세 | Airborne | 예측형 Barrage와 Plasma 증가 |
| 지상 체류 우세 | Grounded | Sky Dive와 지면 Tail Sweep 증가 |
| 좌/우 이동 편향 | Left/Right Bias | 탄막 조준점과 강하 위치를 해당 방향 앞으로 예측 |
| 패링 성공 | False Data | 데이터 무결성/적응 강도 감소, 보스 경직 |

모든 공격의 최소 가중치는 남겨 두어 특정 플레이 방식을 완전히 봉쇄하지 않는다. 학습은 난이도 상승 장치인 동시에 플레이어가 읽고 조작하는 공략 대상이다.

## 조작과 플레이테스트 체크

- 방향키: 이동/점프/앉기
- Q: 근접, W: 원거리, E: 패링, R: 대시
- G: 현재 관찰 데이터 디버그 로그
- Enter: 승패 후 재시작

검증할 핵심 시나리오는 `근접 위주`, `원거리 위주`, `공중 체류`, `한쪽 대시 반복`, `Phase 1 패링 4회 이상`, `Phase 2 연속 패링`이다. 각 시나리오에서 HUD의 판정과 실제 패턴 비중이 일치하는지 확인한다.

## 다음 보스로 확장하는 방법

`PlayerCombatTracker`의 확정 결과를 다음 씬으로 전달하는 세션 데이터 계층을 추가하면 이전 보스전 습관을 후속 LLM 보스가 기억하게 만들 수 있다. 각 보스는 같은 관찰값을 사용하되 카운터 패턴과 교란 미니게임만 다르게 구성한다.

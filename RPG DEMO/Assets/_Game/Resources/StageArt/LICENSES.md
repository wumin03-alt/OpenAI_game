# Stage 01~03 Art Sources

- `Dog_Idle.png`, `Dog_Jump.png`: user-provided robot-dog animation sheets. Used only for the Stage03 defense target.
- `Stage_Background_01.png`, `Stage_Background_02.png`: user-provided stage background art.
- `Stage_Background_03.png`: derived from the user-provided third background; only the duplicated `SECTOR 01` label was corrected to `SECTOR 03` with the built-in image generation edit tool.
- `Melee_*.png`: user-provided melee enemy animation sheets. The bright checkerboard is removed at render time by `StageArtColorKey.shader`; source pixels are preserved.
- `Ranged_*.png`: user-provided ranged enemy animation sheets.
- `Stage_Projectile_Red.png`: user-provided red ranged-enemy projectile animation.
- `Stage_Ground_Long.png`: user-provided long ground tile used by Stage01~03 floors.
- `Stage_Platform_Short.png`: user-provided short structure tile used by Stage01~03 upper platforms.

The user supplied these assets for this project. No external marketplace package or third-party download was added by this change.
